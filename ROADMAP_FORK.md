# ROADMAP — форк `my/mcp-server-and-ci`

Цель форка: довести DeepSeek++ до **«бесконечного» агента**, которому **не нужно заново напоминать контекст**.

> Источник фактов — вики проекта: https://deepwiki.com/zhu1090093659/deepseek-pp/1-overview

## Что уже есть в upstream (v1.14.0)

| Подсистема | Что делает | Файлы (по вики) |
|---|---|---|
| **Inline Agent Loop** | Цикл: генерация → tool-call → исполнение → продолжение | `core/agent/*` |
| **XmlToolStreamFilter** | Парсит tool-call из потока токенов | `core/interception/*` |
| **Memory (RAG-lite)** | 4 типа памяти (user/feedback/topic/reference), pin, injection в промпт | `core/memory/*`, `MemoryPage.tsx` |
| **Skills** | Slash-команды (`/skill`), импорт с GitHub | `core/skill/registry.ts` |
| **Projects & Saved Items** | Группировка инструкций + проектной памяти + диалогов | `entrypoints/sidepanel/pages/*` |
| **Automation** | Запуск задач в dedicated-сессиях по Cron/RRULE | `core/automation/*` |
| **MCP** | 5 транспортов (Streamable HTTP / HTTP / SSE / Studio Bridge / Native) | `core/mcp/transports/*` |

## Чего не хватает (цели форка)

### 🟢 Цель A — Project context file (`AGENTS.md`)

**Проблема:** каждый раз надо напоминать контекст проекта.

**Решение:** читать файл `AGENTS.md` (или `CLAUDE.md`) из папки проекта (Settings → Project Folders) и **автоматически вставлять его в system prompt** каждой сессии этого проекта.

**План:**
1. Добавить загрузчик файла в `core/projects/` (или `core/memory/`).
2. В **Prompt Augmentation** (уже есть в плагине!) добавить вставку содержимого `AGENTS.md`.
3. UI: в Projects — указать путь к context-файлу.
4. Тест: новый чат в проекте → проверяем, что контекст подтянулся.

**Готовый паттерн:** Claude Code (`CLAUDE.md`), Codex (`AGENTS.md`).

### 🟡 Цель B — Context compression (сжатие истории)

**Проблема:** сессия рвётся из-за переполнения контекстного окна.

**Решение:** при росте истории > N токенов — **суммаризировать старые шаги** отдельным запросом к модели и **подменять** их кратким резюме в истории.

**План:**
1. Счётчик токенов — уже есть в `core/token/estimator.ts` (1 CJK ≈ 0.6 tok, 1 ASCII ≈ 0.3 tok).
2. Порог в конфиге (напр. 80% окна).
3. Суммаризатор: N старых сообщений → резюме (отдельный запрос).
4. Подмена истории перед отправкой (в `DeepSeek API Adapter`).
5. Сохранять оригинал (для отката/аудита).

**Готовый паттерн:** Claude Code (auto-compact), MemGPT.

### 🔴 Цель C — Sub-agents (подагенты)

**Проблема:** главный агент «пухнет» от контекста подзадач.

**Решение:** главный агент вызывает **подагента с чистой сессией** для подзадачи; подагент возвращает только **результат**, не весь свой контекст.

**План:**
1. Оркестратор над Inline Agent Loop.
2. API: `spawn_subagent(task, tools)` → изолированная сессия → результат.
3. Главный агент **не видит** промежуточные шаги подагента (только summary).
4. UI: Step-блок «subagent: <task>».

**Готовый паттерн:** Claude Code subagents, AutoGen.

### 🔵 Цель D — Checkpoint / Resume

**Проблема:** при обрыве сессии теряется прогресс.

**Решение:** сохранять состояние (прогресс + ключевые результаты) в файл; при новой сессии — **читать и продолжать**.

**План:**
1. Чекпоинт-файл (напр. `progress.md`) в проекте.
2. Авто-сохранение после каждого шага (или по требованию).
3. При старте сессии — предложить «продолжить с чекпоинта».

**Готовый паттерн:** Claude Code (checkpoints), `docs/progress/MASTER.md` (у самого DeepSeek++ — для разработки, не для пользователя).

## Порядок реализации

1. **A (context file)** — быстро, максимальный эффект для «не напоминать контекст».
2. **D (checkpoints)** — быстро, страховка от обрывов.
3. **B (compression)** — среднее, решает переполнение.
4. **C (sub-agents)** — сложное, максимум автономности.

## Критерий готовности «бесконечного агента»

- [ ] `AGENTS.md` грузится автоматически в каждую сессию проекта.
- [ ] История сжимается при росте (без потери сути).
- [ ] Подзадачи идут через sub-agents (главный контекст не пухнет).
- [ ] Прогресс сохраняется в чекпоинт и восстанавливается.
- [ ] Всё это **без ручного напоминания контекста** пользователем.
